# Tom Version Builder - User Guide

The `versioner` tool provides automated version file generation for Dart projects with build information, git commit tracking, and build number management.

## Overview

Tom Version Builder enables:
- Automatic version.g.dart generation from pubspec.yaml
- Build number tracking and auto-increment
- Git commit hash embedding
- Build timestamp recording
- Dart SDK version tracking
- Project auto-discovery and scanning

## Configuration

The tool uses a two-tier configuration pattern:

### 1. Project Discovery - tom_build.yaml (Optional)

Create a `tom_build.yaml` file in your project root for CLI options:

```yaml
# tom_build.yaml
versioner:
  project: .
  scan: ../
  recursive: true
  verbose: false
  output: lib/src/version.g.dart
  includeGitCommit: true
```

**CLI Options:**
- `project`: Path to specific project
- `scan`: Directory to scan for projects
- `recursive`: Process subprojects recursively
- `exclude`: Glob patterns for projects to exclude
- `recursion-exclude`: Patterns to exclude from recursive traversal
- `verbose`: Show detailed output
- `output`: Path for generated version file
- `includeGitCommit`: Whether to include git commit hash

### 2. Version Configuration - build.yaml

Define version generation settings in `build.yaml`:

```yaml
targets:
  $default:
    builders:
      tom_version_builder:version_builder:
        enabled: true
        options:
          output: lib/src/version.g.dart
          includeGitCommit: true
          variablePrefix: myApp
```

## Configuration Fields

### `output` (string, optional, default: `lib/src/version.g.dart`)

Path for the generated version file, relative to project root.

**Examples:**
```yaml
output: lib/src/version.g.dart
output: lib/version.dart
output: lib/src/app_version.g.dart
```

### `includeGitCommit` (boolean, optional, default: `true`)

Whether to include git commit hash in the version file.

**Example:**
```yaml
includeGitCommit: true   # Include git commit
includeGitCommit: false  # Skip git operations
```

### `variablePrefix` (string, optional, default: `tomTools`)

Prefix for generated variable names (not yet implemented in current version).

## Generated Version File

The tool generates a `version.g.dart` file with the following structure:

```dart
// GENERATED FILE - DO NOT EDIT
// Generated by versioner at 2026-02-06T10:30:45.123Z

/// Version information generated at build time.
/// 
/// This class contains static fields and methods for accessing
/// version information embedded during the build process.
class TomVersionInfo {
  TomVersionInfo._();

  /// Package version from pubspec.yaml
  static const String version = '1.0.0';

  /// Build timestamp (ISO 8601 UTC format)
  static const String buildTime = '2026-02-06T10:30:45.123Z';

  /// Git commit hash (short form)
  static const String gitCommit = 'abc1234';

  /// Build number (increments with each build)
  static const int buildNumber = 42;

  /// Dart SDK version used to build
  static const String dartSdkVersion = '3.10.4';

  /// Short version string: version + build number
  /// Example: "1.0.0+42"
  static String get versionShort => '$version+$buildNumber';

  /// Medium version string: version + build number + git commit + build time
  /// Example: "1.0.0+42.abc1234 (2026-02-01T10:30:00.000Z)"
  static String get versionMedium => '$version+$buildNumber.$gitCommit ($buildTime)';

  /// Long version string: includes all available information including SDK version
  /// Example: "1.0.0+42.abc1234 (2026-02-01T10:30:00.000Z) [Dart 3.x.x]"
  static String get versionLong => '$version+$buildNumber.$gitCommit ($buildTime) [Dart $dartSdkVersion]';
}
```

## Build Number Tracking

The tool maintains build numbers in `tom_build_state.json` in the project root:

```json
{
  "buildNumber": 42,
  "lastBuildTime": "2026-02-06T10:30:45.123Z"
}
```

**Behavior:**
- Build number starts at 1
- Increments by 1 with each version generation
- Persists across builds
- Independent per project

## Usage

### Command Line

```bash
# Generate version file for current project
dart run tom_version_builder:versioner

# Process specific project
dart run tom_version_builder:versioner --project=my_app

# Scan directory for projects
dart run tom_version_builder:versioner --scan=. --recursive

# Custom output path
dart run tom_version_builder:versioner --output=lib/version.dart

# Exclude git commit
dart run tom_version_builder:versioner --no-git

# Verbose output
dart run tom_version_builder:versioner --verbose

# Exclude projects
dart run tom_version_builder:versioner --scan=. --exclude='**/node_modules/**'
```

### Options

```
-p, --project           Path to specific project
    --projects          Glob patterns for projects to process
-s, --scan             Directory to scan for projects
-r, --recursive        Process subprojects recursively
-e, --exclude          Glob patterns for projects to exclude
    --recursion-exclude Glob patterns to exclude from recursive traversal
    --output           Output path for version file
    --no-git           Exclude git commit hash
    --version          Override version from pubspec.yaml
-v, --verbose          Show detailed output
-h, --help             Show help message
```

## Examples

### Example 1: Basic Setup

Minimal configuration:

```yaml
# build.yaml
targets:
  $default:
    builders:
      tom_version_builder:version_builder:
        enabled: true
```

Generates `lib/src/version.g.dart` with default settings.

### Example 2: Custom Output Location

```yaml
# build.yaml
targets:
  $default:
    builders:
      tom_version_builder:version_builder:
        enabled: true
        options:
          output: lib/version.dart
```

### Example 3: Multiple Projects

Process all projects in a workspace:

```bash
# Generate version files for all projects
dart run tom_version_builder:versioner --scan=. --recursive
```

### Example 4: Without Git

For projects not in git repositories:

```yaml
# build.yaml
targets:
  $default:
    builders:
      tom_version_builder:version_builder:
        enabled: true
        options:
          includeGitCommit: false
```

Or via command line:

```bash
dart run tom_version_builder:versioner --no-git
```

### Example 5: CI/CD Integration

In CI/CD pipeline with version override:

```bash
# Override version for release builds
dart run tom_version_builder:versioner --version=1.2.3
```

## Using Generated Version Info

### In Your Application

```dart
import 'package:my_app/src/version.g.dart';

void main() {
  print('App version: ${TomVersionInfo.versionShort}');
  print('Build time: ${TomVersionInfo.buildTime}');
  print('Git commit: ${TomVersionInfo.gitCommit}');
  print('Build number: ${TomVersionInfo.buildNumber}');
  
  // Full version string
  print('Full version: ${TomVersionInfo.versionLong}');
}
```

### In CLI Tools

```dart
import 'package:my_cli/src/version.g.dart';

void printVersion() {
  print('my_cli ${TomVersionInfo.versionMedium}');
}

void printDetailedVersion() {
  print('my_cli version ${TomVersionInfo.version}');
  print('Build: ${TomVersionInfo.buildNumber}');
  print('Commit: ${TomVersionInfo.gitCommit}');
  print('Built: ${TomVersionInfo.buildTime}');
  print('Dart SDK: ${TomVersionInfo.dartSdkVersion}');
}
```

### In About Dialogs

```dart
import 'package:flutter/material.dart';
import 'package:my_app/src/version.g.dart';

class AboutScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('About')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('My App', style: Theme.of(context).textTheme.headlineMedium),
            SizedBox(height: 8),
            Text('Version ${TomVersionInfo.versionShort}'),
            Text('Build ${TomVersionInfo.buildNumber}'),
            if (TomVersionInfo.gitCommit != 'unknown')
              Text('Commit ${TomVersionInfo.gitCommit}'),
            SizedBox(height: 16),
            Text(
              'Built ${TomVersionInfo.buildTime}',
              style: Theme.of(context).textTheme.bodySmall,
            ),
          ],
        ),
      ),
    );
  }
}
```

## Integration with build_runner

Add version builder to your build pipeline:

```yaml
# build.yaml
targets:
  $default:
    builders:
      # Generate version first
      tom_version_builder:version_builder:
        enabled: true
        options:
          output: lib/src/version.g.dart
      
      # Then other builders
      json_serializable:
        enabled: true
```

Run with:

```bash
dart run build_runner build
```

## Project Discovery

A project is considered a "version project" if it:
1. Contains a `pubspec.yaml` file
2. Contains either:
   - A `tom_build.yaml` file with `versioner:` section, or
   - A `build.yaml` file with `tom_version_builder:version_builder` configuration
3. Is not a builder definition project itself

## Best Practices

### 1. Consistent Location

Use a consistent output location across projects:

```yaml
output: lib/src/version.g.dart
```

### 2. Add to .gitignore

Version files are generated, so exclude them from git:

```gitignore
# .gitignore
**/version.g.dart
tom_build_state.json
```

### 3. Generate Before Build

Always generate version files before building releases:

```bash
# In your build script
dart run tom_version_builder:versioner
dart compile exe bin/app.dart
```

### 4. Display Version in App

Show version information to users:

```dart
// Splash screen, about dialog, or --version flag
print('App ${TomVersionInfo.versionMedium}');
```

### 5. Log Version at Startup

Log version info when your app starts:

```dart
void main() {
  print('Starting app ${TomVersionInfo.versionLong}');
  runApp(MyApp());
}
```

## Troubleshooting

### "No projects found to process"

**Cause:** No project with version configuration found.

**Solution:** Add version builder configuration to `build.yaml` in your project.

### Git commit shows "unknown"

**Possible causes:**
1. Project not in a git repository
2. Git not installed or not in PATH
3. No commits in repository yet

**Solutions:**
- Initialize git repository: `git init && git commit -m "Initial commit"`
- Install git if missing
- Use `--no-git` flag to skip git operations

### Build number not incrementing

**Possible causes:**
1. `tom_build_state.json` file was deleted
2. File permissions prevent writing
3. Multiple parallel builds

**Solutions:**
- Build number will restart from 1 if state file is missing
- Check file permissions in project directory
- Avoid parallel version generation for the same project

### Version not updating

**Cause:** Version file already exists and wasn't regenerated.

**Solution:** 
- Delete the generated version file
- Run versioner tool again
- Ensure build_runner is using `--delete-conflicting-outputs`

### Wrong Dart SDK version

**Cause:** Version captured at generation time, not runtime.

**Solution:** This is expected - the SDK version reflects the build environment, not the runtime environment.
